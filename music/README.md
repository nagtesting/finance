# Background music

Drop ONE royalty-free MP3 in this folder. The publisher picks up the first
.mp3 / .m4a / .wav it finds.

If this folder is empty, the publisher falls back to a synthesized ambient
pad (sine wave at 146.83 Hz, very low volume) so the video still ships —
but a real track sounds dramatically better.

## Where to get free, YouTube-safe music

YouTube Audio Library is the safest source — anything you download there is
explicitly licensed for use on YouTube with no copyright strike risk:

  https://www.youtube.com/audiolibrary

Filter to:
  - Genre: Cinematic / Ambient
  - Mood: Calm / Inspirational
  - Duration: 1:00+ (the publisher will loop and trim to ~57s)
  - Attribution required: No  ← simpler

Suggested vibe for MoneyVeda: slow ambient pad, subtle piano, no vocals,
no drum hits. Search terms that tend to surface good options:
  "ambient piano", "calm strings", "morning briefing", "slow cinematic"

## Naming

Anything works. The publisher sorts alphabetically and picks the first
match, so prefix with `01-` if you ever keep multiple options here and
want to control which one is used:

  music/
    01-morning-briefing.mp3   ← used
    02-alt-track.mp3
